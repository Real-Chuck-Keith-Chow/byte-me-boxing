Requirement Document: 

The device attaches to a heavy bag and uses two sensors: one to measure punch force and one to record punch sound. A Raspberry Pi Pico 2 reads both sensors and detects each punch as it happens. Each punch's force, sound, and type are saved to a memory card for later graphing on a computer. An LED lights up to show feedback right away.





Specification: 

This device must be able to attach to a heavy bag 


Constraints: 
What pressure sensors should be bought. How are they going to be stuck
Heavy Bag will be moving. Interference from noise and tape will happen
